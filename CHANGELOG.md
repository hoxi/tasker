# Changelog

## [2026.2.1]

- **Every Task Management server type** is now listed, not just those with a Tasker adapter
- **Jira** joins GitHub, GitLab and YouTrack: in-place editing, its own status names, issue types and priorities
- **Comments** rendered by the tracker, with avatars, threaded replies and emoji reactions; edit your own in place
- **Details pane** shows priority, labels, linked pull and merge requests, and — for Jira and YouTrack — the epic,
  parent, sub-tasks and other linked issues
- **Assignee column**
- **Sorting** by several rules from column headers or a new sort popup: status in workflow order, priority, dates and
  an assignee ranking; save a sort with *Done* and bring it back with *Restore*
- **Active task** marked with a yellow arrow, earlier started tasks with a grey one; right-click the active task to
  edit it
- **Dates** follow the IDE's date format, including "5 minutes ago" with pretty formatting on
- **Caching** follows Task Management's issue cache interval, with fewer requests per list and per selected task
- View settings are remembered per project, and the list reloads after the servers are reconfigured
- Works with Task Management installed from the Marketplace, as needed from 2026.2; verified against 2026.1 too
